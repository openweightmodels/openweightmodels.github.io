What is Qwen3 8B?

Qwen3 8B is an open-weight AI model published by Qwen / Alibaba. OpenWeightModels includes it for reasoning, multilingual chat, coding and local RAG. The recorded license is Apache 2.0; the practical deployment envelope is classified as ≤8B · consumer/local.
