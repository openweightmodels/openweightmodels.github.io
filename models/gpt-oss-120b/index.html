Overview

What this model is.

gpt-oss-120b is a text-only Mixture-of-Experts reasoning model released by OpenAI. It uses 36 layers, 128 experts and activates four experts per token.

The model was post-trained for configurable reasoning effort, tool-oriented workflows and structured outputs. OpenAI documents a 131,072-token context window and a checkpoint size of about 60.8 GiB.

Why it is in the registry

This model represents a materially different combination of architecture, license and deployment requirements from the other full passports.

Hardware

Deployment scale matters.

OpenAI reports a 60.8 GiB checkpoint and specifically designed the model to fit on a single 80 GB accelerator. Runtime buffers, KV cache and workload shape still add memory overhead.

Methodology note: OpenWeightModels avoids publishing a single “required GPU” number unless it is explicitly documented for a defined checkpoint/runtime. Precision, context length, KV cache, batching and runtime overhead can materially change hardware needs.
