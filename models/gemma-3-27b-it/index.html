Overview

What this model is.

Gemma 3 is Google's open-weight multimodal family built from technology related to Gemini. The 27B instruction-tuned checkpoint accepts text and image input and produces text output.

Google documents support for more than 140 languages and a 128K context window for Gemma 3. The licensing model is custom and should be tracked separately from Apache- or MIT-licensed models.

Why it is in the registry

This model represents a materially different combination of architecture, license and deployment requirements from the other full passports.

Hardware

Deployment scale matters.

A 27B dense model is much more accessible than the giant MoE models in this registry, but full-precision deployment is still memory-intensive. Quantized variants can materially reduce local hardware requirements, with corresponding quality/performance trade-offs.

Methodology note: OpenWeightModels avoids publishing a single “required GPU” number unless it is explicitly documented for a defined checkpoint/runtime. Precision, context length, KV cache, batching and runtime overhead can materially change hardware needs.
