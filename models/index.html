FAQ

How to read the directory.

What is an open-weight model directory?

It is a structured index of models whose trained weights are obtainable, with separate records for architecture, licensing and deployment evidence.

Are all models in this directory open source?

No. Open weight describes weight availability. Some entries use Apache 2.0 or MIT, while others use custom model terms such as the Llama Community License, Gemma Terms or the Qwen License.

Can every model be self-hosted?

Weight access can make independent deployment possible, but practical feasibility varies from consumer-class 3B models to datacenter-scale mixture-of-experts models.

How are model facts verified?

OpenWeightModels prioritizes exact model cards, license files, official repositories and named deployment-provider documentation, with a visible verification date.
