# Open Weight Models

**Independent reference for open-weight AI models, licenses, hardware, inference, deployment and structured model data.**

Website: **https://openweightmodels.github.io/**

## Purpose

Open Weight Models is a source-first reference for developers, researchers and infrastructure teams working with AI models whose trained weights are publicly available.

The project tracks model identity, architecture, weight access, licenses, commercial-use conditions, formats, quantization, hardware requirements, inference runtimes, deployment paths and primary sources.

## Editorial principles

- Prefer primary sources: official model cards, repositories and license documents.
- Treat **open weights** and **open source** as distinct concepts.
- Treat licensing as a first-class technical attribute.
- Do not infer commercial rights from the word “open”.
- Record verification dates for structured data.
- Summarize third-party material and link to the authoritative source.
