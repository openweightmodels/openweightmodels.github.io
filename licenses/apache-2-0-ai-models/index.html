What Apache 2.0 means

Permissive rights with concrete notice obligations.

Apache License 2.0 generally allows use, reproduction, modification, public performance/display, sublicensing and distribution of the licensed work, including in commercial settings.

Redistribution is not obligation-free. The license requires a copy of Apache 2.0, prominent notices for modified files, retention of relevant copyright/patent/trademark/attribution notices, and treatment of a NOTICE file as specified when the distribution includes one.

Apache 2.0 also contains an express patent license from contributors. That is one reason it is often operationally attractive for software and model releases compared with very short permissive licenses.

For AI models, however, a model's weight license is only one layer. Training data, accompanying code, acceptable-use policies, hosted-provider terms and application law can be separate questions. OpenWeightModels therefore labels these exact models “Apache 2.0” without automatically calling every surrounding system fully open source.

FAQ

Apache 2.0 and AI models.

Can Apache 2.0 AI models be used commercially?

Apache License 2.0 permits commercial use, modification and redistribution subject to its conditions. Separate model policies or applicable law can still matter and should be checked for the exact release.

Does Apache 2.0 make an AI model fully open source?

Not automatically. A weights license does not by itself establish that training data, training code and every component satisfy an Open Source AI definition.

What attribution does Apache 2.0 require?

Redistributions must include a copy of the license, preserve required notices, identify modified files, and handle a NOTICE file as specified by the license when one is supplied.

Why does OpenWeightModels list the exact model instead of just the family?

Licensing can differ between sizes, versions or adjacent model families. The exact artifact and license file are the unit of verification.
