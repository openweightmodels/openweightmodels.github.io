Responsibility

Controller and scope.

This privacy policy applies to the public website openweightmodels.eu and the static pages and data files delivered under this domain.

The controller is the operator of the independent Open Weight Models reference project. This policy covers processing associated with the public website and its first-party files.

If a separate statutory legal notice is published for this website, the operator identity and contact details stated there should be read together with this privacy policy. OpenWeightModels does not infer or publish private operator information automatically.

This policy concerns the website itself. Links to external model developers, repositories, cloud providers or documentation lead to independent third-party services with their own privacy practices.

Hosting

External hosting.

This website is delivered through an external hosting provider. Technical connection data, in particular the IP address, may be processed when the site is requested.

The processing is necessary for secure, stable and reliable delivery of the website. The hosting provider is GitHub. OpenWeightModels does not add a separate audience-analytics or advertising-tracking layer on top of the hosting process.

For information about the provider's own processing, retention and recipients, see the GitHub Privacy Statement ↗.

Tracking & storage

What this site deliberately does not use.

The current site code is designed to work without behavioral profiling or persistent browser storage.

ANALYTICS

No visitor analytics

No Google Analytics, Google Tag Manager, Cloudflare Web Analytics, Microsoft Clarity, Matomo, Plausible, Hotjar or similar analytics script is embedded in the current site.

ADVERTISING

No marketing trackers

No Meta Pixel, Google Ads conversion tag or comparable advertising/retargeting technology is embedded.

BROWSER STORAGE

No non-essential storage

The current website code does not use cookies, Local Storage or Session Storage for analytics, personalization or advertising.

FONTS

No external web fonts

The interface uses local/system font stacks. Visiting a page does not require a request to Google Fonts or another external font CDN.

EMBEDS

No third-party media embeds

No YouTube player, social-media widget, map embed or similar third-party iframe is loaded automatically on page view.

PROFILING

No user profiles

OpenWeightModels does not create individual browsing profiles, advertising audiences or cross-site identifiers.

No analytics consent banner: because the site itself does not currently deploy non-essential analytics, marketing tracking or persistent personalization storage, it does not present an analytics/marketing consent banner. If the technical setup changes, this policy and the consent approach must be reviewed before or together with that change.
External sources

Links are not embeds.

OpenWeightModels links extensively to primary sources such as model publishers, GitHub repositories, Hugging Face, cloud documentation and license texts.

These links are ordinary hyperlinks. The linked third-party service is not contacted merely because an OpenWeightModels page contains the link. A connection to the third-party service is generally initiated when you choose to open the link.

Once you leave openweightmodels.eu, the privacy policy and technical behavior of the destination service apply. OpenWeightModels cannot control the processing carried out by those independent services.

Legal basis & retention

Technical delivery and security.

The website does not maintain its own audience analytics database.

01

Website delivery

Where the operator is responsible for technical processing necessary to make the website securely available, the processing is based on the legitimate interest in providing a stable, secure and abuse-resistant information service, Art. 6(1)(f) GDPR, where applicable.

02

Provider logs

GitHub controls the technical logs generated within its hosting infrastructure. OpenWeightModels does not use those provider-side security logs to build visitor profiles or advertising audiences.

03

Retention

OpenWeightModels does not maintain separate analytics or tracking retention periods because it does not collect such data. Provider-side retention is governed by the applicable GitHub documentation and privacy terms.

Data subject rights

Your privacy rights.

Where the GDPR applies and the legal requirements are met, data subjects may have rights regarding personal data processed by the controller.

These may include the right of access, rectification, erasure, restriction of processing, data portability where applicable, and the right to object to processing based on legitimate interests.

You also have the right to lodge a complaint with a competent data protection supervisory authority. Which supervisory authority is competent depends on the controller's establishment and the circumstances of the processing.

For processing performed independently by GitHub, requests concerning GitHub's own data processing may also need to be directed to GitHub in accordance with its privacy statement.

Search & machine-readable files

Public indexing is not visitor tracking.

OpenWeightModels publishes public technical files such as sitemap.xml, robots.txt, llms.txt and structured JSON records. These files describe public website content for search engines, tools and AI systems. They do not contain visitor profiles or individual browsing histories.

Search engines may crawl publicly accessible pages according to their own systems and policies. This is separate from embedding a client-side analytics tracker in the website.

If OpenWeightModels later introduces a reverse proxy, security service, contact form, analytics service, embedded media or other technology that changes personal-data processing, the policy should be updated to reflect the actual configuration before or together with the change.
